EDI (Electronic Data Interchange) is the connection that lets SimplePractice send claims straight to a payer instead of you mailing or faxing paper claims. It's a one-time setup — per payer.

Find EDI enrollment in Settings, select a payer, and fill out the form: clinician info (NPI, and your Tax ID — this is where it actually goes, not Lesson 2's Practice Settings) and practice info.

Once submitted, status shows as pending until the payer approves it. Timelines vary — anywhere from a few days to a few weeks. Do this for every payer you take.

Takeaway — Your Tax ID goes on the EDI enrollment form, not Practice Settings. Enroll payer by payer — approval can take days to weeks.

Services and CPT codes live in Settings, where you set a single practice-level default rate per code — 90791 for intakes, 90834 and 90837 for 45- and 60-minute therapy, 90847 for family/couples.

SimplePractice doesn't have separate "self-pay rate" and "insurance rate" fields on a service code — there's just the one default. If a specific client needs something different (a contracted insurance rate, a sliding-scale rate), you set that on their profile, under Billing and Insurance → Client Default Services, which overrides the practice default just for them.

Double-check telehealth modifiers and place-of-service codes, and make sure each service maps to the right appointment type.

Takeaway — One default rate per CPT code at the practice level. Client-specific rates (contracted, sliding-scale) go on that client's profile under Client Default Services — not on the code itself.
